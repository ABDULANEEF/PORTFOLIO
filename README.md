
  # Abdul Aneef | Portfolio

This is my personal portfolio website built with React, Vite, and Tailwind-inspired styling. It showcases my work as a Data Science Enthusiast with sections for my introduction, technical strengths, projects, and contact details.

## About this project

This portfolio is designed to present:

- My identity and professional profile
- My technical skills and learning journey
- Selected projects and work experience
- A modern and responsive portfolio layout for web visitors

## Tech stack

- React
- Vite
- TypeScript
- Framer Motion
- Tailwind CSS patterns
- Custom UI components

## Local setup

1. Install dependencies:
   npm install

2. Start the development server:
   npm run dev

3. Open the local URL shown in the terminal to view the site.

## Production build

npm run build
